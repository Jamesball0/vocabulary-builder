# Vocabulary Builder

A personal application for learning and storing vocabulary.

## Features

- Word and meaning records
- Search vocabulary
- Local storage

## How to Use

Enter a new word and its meaning, then save it.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist
